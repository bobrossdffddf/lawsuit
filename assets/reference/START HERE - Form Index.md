# Clearwater County Legal System

The complete court system for Clearwater County, Sixth Judicial Circuit — a two-tier trial
structure (County Court and Circuit Court) with an Appellate Court above them and the Supreme
Court of the State above that.

**45 editable PDF forms · 119 pages · 3,063 fillable fields · 3 reference publications**

Every PDF is a real AcroForm. Open it in any PDF reader, click a field, and type. Checkboxes tick.
Nothing needs to be printed.

## The four paths through the system

**Criminal** — CR-01 → CR-06 → CR-03 → CR-07 *or* trial → CR-10 → CR-11 → AP-01

**Claim against a department** — AD-05 → AD-03 → **CV-04 (mandatory, 45-day wait)** → CV-01 → CV-02 → CV-03 → CV-07 → CV-09 or CV-10

**Traffic** — TR-01 → TR-02 → (TR-03 or TR-04) → TR-05 if unresolved

**Appeal** — JR-01 / CR-10 → AP-01 → AP-03 → AP-02 (rare)

## Conventions

- **Case numbers** use `YY-TYPE-NUMBER` — `26-CF-000123`. Type codes: CF felony, MM misdemeanour,
  CT criminal traffic, TR civil traffic, MO ordinance, CC county civil, CA circuit civil,
  SC small claims. Appellate cases use `A-2026-000123`; Supreme Court cases use `SC-2026-000123`.
- **Sentences** in the Charge and Penalty Code are the standard starting term for an ordinary case,
  not the ceiling. The ceiling is the class maximum.
- **Jurisdiction thresholds** — Small Claims to $8,000; County Civil to $50,000; Circuit Civil above
  $50,000. Circuit Court hears all felonies; County Court hears everything else.
- Clearwater County is a fictional jurisdiction. Every page carries a footer saying so.
